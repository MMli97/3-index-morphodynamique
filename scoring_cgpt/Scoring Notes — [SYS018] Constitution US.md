# **Lecture morphodynamique**

La Constitution US apparaît ici comme un **cas quasi-limite du modèle** :

- Couplage maximal A2–A3

- Normativité stabilisée mais révisable (A4 ≈ A5)

- Hiérarchie profonde + circulation bidirectionnelle

Ce que montre très bien Ackerman :

→ le système combine **stabilité constitutionnelle** et **révisions discontinues par mobilisation populaire (“higher lawmaking”)**

Donc :

- ni rigide (A5 élevé)

- ni fluide (A4 élevé)

- mais **oscillation structurée entre les deux**

---

# **Point critique (important pour ton cadre)**

Ce système révèle une propriété rare :

→ **coïncidence A4 ≈ A5 à haut niveau**

C’est typiquement :

- impossible dans les systèmes biologiques simples

- rare dans les systèmes techniques

- mais possible dans les systèmes politiques historiquement stratifiés
